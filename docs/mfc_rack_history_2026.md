# 2026년 렉 코드 기간별 변화

작성일: 2026-10-16

과거 레이아웃을 다시 작성할 때 참고하도록 2026년 출고(1/1~9/27)에 나타난 렉 코드의
등장·종료·재등장을 기간별로 정리한다. 원천 계산은
[11_rack_code_history_2026.ipynb](../notebooks/11_rack_code_history_2026.ipynb)이고 결과 파일은
`reports/mfc_rack_history_2026/`에 있다.

## 읽기 전 주의

- **모든 내용은 출고 기록 관측이며 사용자 확인 전이다.** 출고가 없는 렉은 코드가 보이지 않으므로
  "종료"를 철거로, "미관측"을 렉 부재로 단정하지 않는다.
- 코드의 이어짐(X→B, 옛 A→D·C)은 시점과 번호가 맞아서 세운 **추정**이다.
- C 도입 전 A는 상온이다. 같은 A 코드라도 7/27 주 이전과 이후는 다른 위치일 수 있다.
- 현재 레이아웃은 `layout_2026-09`(2026-08-10 이후 유효)이다. "현재에 없음"은 이 레이아웃과
  비교한 결과다.
- 렉 코드 752개, 출고 2,376,631행, 월요일 시작 39주. 판정 기준은 `GAP_WEEKS=3`(3주 이상 공백이면
  종료·재등장), `LOW_ROWS=10`, `BOUNDARY_MIN=10`(한 주에 변화 코드 10개 이상이면 구간 경계 후보)이다.

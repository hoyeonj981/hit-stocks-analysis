## 제안 산식

사용자는 ‘수직 이동’이 **각 구역 안쪽으로 들어가는 방향**이며 렉 선반 높이는
생략한다고 확인했다(2026-10-16). 이를 주 이동 방향으로 정의하고, 그 길에서 옆으로
빠지는 이동을 복도 안 추가 진입으로 구분한다. 주 이동 방향이 그림의 Y축과 일치한다고
가정하지 않는다.

\[
\widehat D(o)=2\{V_{상온}(o)+V_{냉장·냉동}(o)\}
+\sum_{j\in J(o)} k_j\max\{0,H_j(o)-\tau_j\}+C(o)
\]

| 항 | 의미 |
| --- | --- |
| `V상온`, `V냉장·냉동` | 패킹에서 각 방향으로 필요한 가장 먼 주 이동 지점까지의 편도 거리. 미방문 방향은 0 |
| `J(o)` | 방문 렉을 포함하는 추가 진입 구간. 같은 진입점에서 같은 방향으로 들어가는 렉끼리 묶음 |
| `Hj` | 해당 구간에서 가장 깊은 방문 렉까지의 편도 추가 진입 거리. 이미 V에 포함된 길은 제외 |
| `τj` | 비교 지수에서 생략할 짧은 진입 거리. 아직 미정이며 0이면 생략하지 않음 |
| `kj` | 같은 입구로 복귀하는 구간은 2. 관통하는 구간은 출구 연결을 확인해 별도 산정 |
| `C(o)` | 앞의 항에 포함되지 않은 출입 연결·기둥 우회 등의 추가 이동. 중복 합산하지 않음 |

이 식은 **각 방향의 주 통로를 왕복하고, 중간에 필요한 복도에 진입하는 근사**다.
각 방향의 필수 주 통로가 하나의 연속된 길이라는 조건이 필요하다.
냉동 방문 시 냉장을 지나는 길, D 방문 시 C를 지나는 길을 각각 두 번 합산하지 않도록
각 방향의 최장 도달거리로 묶는 안이다. 실제 출입구·연결이 이 구조와 맞는지는 확인 전이다.
독립된 가지가 있으면 그 가지의 추가 왕복을 별도로 넣어야 한다.

현재 운영의 기본 원칙인 S-Shape 전체를 재현하는 식은 아니다. 관통 복도에 무조건 `2H`를
적용하지 않는다. 관통 길이와 다음 구간 연결을 별도 고정 규칙으로 정하고,
주 통로에서 이미 센 길과 중복되지 않게 반영한다. 근거 없는 계수로 이를 맞추지 않는다.

`max(0, H-τ)`는 문턱을 넘은 부분만 반영하는 제안이다. 짧은 이동도 실제로는 발생하므로
이를 적용한 결과는 거리의 정확한 합이 아니다. 작은 이동이 여러 복도에서 반복되는 주문은
과소평가될 수 있어 `τ=0` 결과와 함께 비교한다.

## 가상 예시와 확인 기준

패킹 기준 상온 최장 편도 12칸, 냉장·냉동 방향 최장 편도 8칸,
추가 진입 구간 두 곳의 깊이가 1칸·5칸, 모두 같은 입구로 복귀한다고 가정한다.
생략 기준 2칸, 별도 우회 0칸이면 `2×(12+8)+2×(0+3)=46`이다.
생략하지 않으면 `2×(12+8)+2×(1+5)=52`다. 모두 설명용 숫자이며 실측 보정값이 아니다.

- 같은 렉의 상품을 추가해도 보행거리는 그대로여야 한다.
- 같은 진입 구간의 최장 지점보다 가까운 렉 추가는 기본 왕복거리를 늘리지 않아야 한다.
- 더 먼 렉이나 별도의 진입 구간 추가는 지수를 낮추지 않아야 한다.
- 반대 방향의 방문이 추가되면 그 방향의 왕복도 반영해야 한다.

## 기존 레이아웃에 연결할 때 남은 사항

- A·B·C_D 좌표는 서로 독립이고 칸 크기도 일정하지 않다. 도면 간 좌표 차이나 렉 번호
  차이를 직접 거리로 쓰지 않는다. 공통 상대 단위와 출입 연결 기준이 필요하다.
- A·B 렉 번호는 왼쪽→오른쪽, C·D는 오른쪽→왼쪽이다. C·D 복도 번호 방향도 서로 다르다.
  번호의 최댓값을 패킹에서 가장 먼 지점으로 간주하지 않는다.
- 렉 중심 좌표는 작업자가 서는 위치가 아니다. 복도상의 대표 피킹 위치와 진입점을 정한다.
  교차 통로 양쪽을 왕복해야 한다면 서로 다른 진입 구간으로 나눈다.
- C08-00은 미배치, D07-01은 철거 렉의 가정 배치다. 미배치 방문을 거리 0으로 처리하지
  않고 계산 누락으로 표시한다. 과거 주문에는 해당 시점의 배치·코드 의미를 확인한다.
- 우선 확인할 것은 패킹 대표점과 구역 출입구, 복도별 왕복·관통 구분이다.
  보정값과 생략 기준은 대표 주문의 손계산·현장 동선과 비교한 뒤 정한다.

## 9월 첫 계산 (2026-10-16)

실행 노트북: [12_mfc_order_distance.ipynb](../notebooks/12_mfc_order_distance.ipynb).
결과: [9월 보고서](../reports/mfc_order_distance/2026-09/summary.md).
설정: [distance_model_2026-09.json](../references/mfc_layout/distance_model_2026-09.json).

사용자가 추가로 확인한 조건:

- 공통 시작·복귀점은 B와 C 사이이며 B09·C04~C06과 가깝다.
- A–B–패킹–C–D 구조다. A를 방문하면 B 통과, D를 방문하면 C 통과가 필수다.
- A 입구는 A06~A08 사이, B에서 A로 가는 출구는 B04 방향이다.

이 조건을 다음의 **잠정 모델 좌표**로 옮겼다. 인접 렉 확인과 정확한 좌표 확인은 다르다.

| 대표점 | 모델 좌표 | 근거 |
| --- | --- | --- |
| 상온 진입 | C_D (1,10) | C05 앞 통로 |
| 냉장 진입 | B (17,7) | B09 근처 통로 |
| 냉장→냉동 출구 | B (0,13) | B04 앞 통로 |
| 냉동 진입 | A (17,13) | A07 앞 통로 |

주 이동 깊이는 상온에서 오른쪽, 냉장·냉동에서 왼쪽이다. 냉동 깊이에는 B의 x=17→0
통과 17칸을 더하고, 주문의 냉장·냉동 깊이 중 최댓값만 왕복한다. A 방문 주문에는 B04
출구를 가상의 필수 경유점으로 추가한다. 실제 피킹 렉 수·방문 빈도에는 포함하지 않는다.

첫 구현은 초안의 진입 구간 `j`를 **같은 깊이의 진열 블록×위/아래**로 묶는다.
상온 블록 경계 x=2·10·17·25, B=8.5·15.5, A=8이며 기존 진열 블록 사이의 빈 공간을
참고한 계산용 구분이다. 같은 블록에서 같은 방향으로 진입하는 렉은 최대 측방 범위만 센다.
이는 실제 개별 복도 왕복·S자 경로를 계산한 결과가 아니며, 블록 내부 반복 진입은 생략된다.
일반 렉의 피킹 위치는 렉 x 중심과 복도 양쪽 면의 중간 y로 근사한다.
B09·A12와 상온 왼쪽 세로 진열면은 인접 세로 통로로 투영한다.

- 공통 단위: 도면 상대 좌표 1칸을 비용 1로 가정한다. 실측 동일 축척은 미확인이다.
- 기본 `τ=0`, `k=2`. 짧은 이동도 포함하며 `τ=2` 결과를 가상 민감도로 함께 저장한다.
- 패킹↔각 입구·B↔A 사이 추가 연결 및 기둥 우회 보정은 0으로 생략한다.
  따라서 통행 가능한 실제 경로의 길이를 보장하지 않는다.
- 자료는 9/1~9/27 출고 요청, SHIPPED, 수량 양수다. 주문번호 단위로 분할 출고를 묶는다.
- 위치 누락이 한 행이라도 있는 주문은 평균·최장 순위에서 제외한다. 알려진 렉의 부분 비용은
  `known_rack_cost`로 따로 보존한다. 히트맵은 전체 주문의 지도 표시 가능한 주문-렉 쌍을 센다.
- 평균 방문 사례는 평균 비용에 가장 가까운 실제 주문이다. 동률이면 요청 시각·주문번호 순이다.
  모든 주문의 평균 방문 위치를 의미하지 않는다.
  후속 요청에 따라 같은 기준으로 대표 주문 10개를 선정해 노트북과
  `mean_representatives.md`에 개별 지도를 저장한다. 비용이 동률이어도 주문별로 유지한다.

현재 산식의 검증은 손계산 예시, 중복 방문, 공유 깊이, 필수 출구와 기존 방문의 중복 제거,
